# 📡 Live Crypto Tracker - Day 45

Real-time cryptocurrency price tracker - BTC, ETH, SOL, ADA
Live from CoinGecko API, no API key needed.

**Main file:** `tracker.py` | **Output:** `crypto_prices.json` (updates every 10s)

### ✨ Features
- Live prices + 24h % change with ▲ / ▼
- Auto-refresh loop `while True`
- Saves to JSON for dashboard use
- Error handling for API timeout
